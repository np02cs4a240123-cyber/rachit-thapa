Flexbox vs Grid (Learning Notes)

Flexbox

Flexbox is a one-dimensional layout system used to arrange items either in a row or a column. It is ideal for aligning elements, spacing items evenly, and building components like navigation bars and cards.

CSS Grid

CSS Grid is a two-dimensional layout system used to work with both rows and columns at the same time. It is perfect for creating full-page layouts or sections like the About area in this portfolio.

✔ For this portfolio, I used CSS Grid to arrange the About section into two columns.
